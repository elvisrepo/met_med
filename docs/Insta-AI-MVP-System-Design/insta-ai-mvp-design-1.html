Django modules

  • auth — invite, one-use reset link (TTL 24h), session JWT httpOnly + CSRF
  • articles — URL normalize, fetch, strip boilerplate, store source
  • generations — category detect, prompt build, caption + image orchestration
  • publishing — IG container → publish, token refresh, retry
  • metrics — tokens_in/out, cost_usd, status, per-user aggregates

Celery tasks (async)

  • fetch_article(article_id) — timeout 15s, retry 2×, extracts title/body/main_image/date
  • generate_caption(generation_id) — LLM text + image in parallel, logs model versions
  • publish_ig(post_id) — 2-step Graph publish, idempotency key = generation_id, requires status=in_review
  • refresh_ig_token() — beat daily, refresh 60-day token, alert admin on fail
  • Sync only: login, review/edit, approve — never block on LLM/IG

Deploy unit

One docker-compose.yml: caddy + web (gunicorn) + worker + beat + db + redis. Same file local + VPS. Caddy terminates SSL, serves / SPA, proxies /api/* + /admin/*. Nightly pg_dump | gzip | rclone → B2, 30-day retention.

2 · End-to-end sequence + failure paths

One post happy path with three explicit failure branches: fetch fail, LLM fail, IG token expired. Mandatory human review gate before any publish call.

Fetch fail

Retry 2× with backoff. Then fetch_failed + manual title/body form. Never block generation queue. Log source domain for paywall list.

LLM fail

Retry 1×, cap spend per attempt. Surface model error code, keep prior draft. Regenerate is per-field (caption-only / image-only) to save cost.

IG token expired

Detect code 190, set post.status=token_expired, Slack/email admin, show Reconnect banner. Publish job parked, idempotent resume after refresh — no duplicate posts.

3 · ERD

Four tables. One article → many generations (edits + regenerates preserved). One generation → at most one post. Every generation logs tokens and cost even on failure.

5 · NFR notes

Targets and guardrails that gate Round 2 (backend / frontend / testing / VPS / monitoring).

Perf · <90s p95 generation

Async Celery; SPA polls /api/generations/:id. Parallel text + image calls. Timeouts: fetch 15s, LLM 60s. P95 measured from POST article → ready_for_review. Alert if p95 > 75s over 1h.

Cost · <$0.10 / post

Log tokens_in/out + cost_usd per generation. Per-field regenerate. Monthly cap env LLM_MONTHLY_CAP_USD; block image regen at 90%. Dashboard avg must stay < $0.07 to leave headroom.

Security · OWASP Top 10 basics

  • JWT httpOnly + Secure + SameSite=Lax, CSRF token, 24h invite TTL, rate-limit login 5/min
  • SSRF guard: fetch allowlist http/https, no private IPs, 5MB body cap
  • IG/LLM keys in server .env only; pip-audit / npm audit + semgrep in CI block merge

Legal · no full-text republication

Store extracted text internally only. Caption = original summary + link/credit to source. Image = AI-generated, no article photos scraped. Delete body on request; pg_dump encrypted at rest on B2.
